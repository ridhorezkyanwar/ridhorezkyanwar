## How I approach projects

- Document the problem, setup steps, and limitations instead of treating a demo as production-ready.
- Validate inputs and pay attention to security boundaries when an app makes network requests or handles sensitive-looking data.
- Keep the implementation and the README aligned; commands and performance claims should be verified before they are advertised.
