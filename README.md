**Software Developer · Applied AI · Cybersecurity**

I build practical software across application security, developer tooling, and machine learning. I value clear documentation, reproducible setup, and interfaces that make technical work easier to use.

## Selected Projects

### Security and developer tools

- **[Sentinel Log Analyzer](https://github.com/ridhorezkyanwar/sentinel-log-analyzer)** — AI-assisted analysis of server, firewall, and access logs, with indicator-of-compromise extraction and structured reports. [Demo](https://sentinel-log-analyzer-phi.vercel.app/)
- **[Security Headers Analyzer](https://github.com/ridhorezkyanwar/security-headers-analyzer)** — checks selected HTTP security headers and HTTPS configuration, then provides a heuristic grade and remediation suggestions. [Demo](https://security-headers-analyzer.vercel.app/)
- **[SysMon-CLI](https://github.com/ridhorezkyanwar/sysmon-cli)** — Python command-line utility for viewing CPU, memory, and root-disk metrics.

### Applied machine learning

- **[ASL Sign Language Classifier](https://github.com/ridhorezkyanwar/sign-language-classification)** — computer-vision project for classifying American Sign Language hand gestures. [Demo](https://sign-language-classification-jtpkzzhypoq4xalf9kzdcs.streamlit.app/)
- **[WhatsApp Notification Router](https://github.com/ridhorezkyanwar/whatsapp-notification-router)** — routes incoming messages into notify, digest, or mute actions using message context and classification logic.
- **[Wine Quality MLOps](https://github.com/ridhorezkyanwar/wine-quality-mlops)** — machine-learning pipeline for wine-quality classification with model serving and monitoring components.
